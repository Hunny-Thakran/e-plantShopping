# Paradise Nursery

## Project Description

Paradise Nursery is an online plant shopping application built using React and Redux. The application allows users to browse different categories of plants, add plants to a shopping cart, and manage the cart by updating quantities or removing items.

## Features

* Landing page for Paradise Nursery
* Product listing page with multiple plant categories
* Display of plant images, names, and prices
* Add to Cart functionality using Redux
* Dynamic cart item count
* Shopping cart page
* Increase and decrease item quantities
* Remove items from cart
* Automatic calculation of total item cost
* Automatic calculation of total cart amount
* Navigation bar with links to Home, Plants, and Cart

## Technologies Used

* React
* Redux Toolkit
* React Router
* JavaScript
* HTML
* CSS

## Installation

1. Clone the repository.
2. Run `npm install`.
3. Run `npm start`.
4. Open the application in your browser.
